## 已知问题与边界

- 显示器按设备名匹配，Windows 重新编号后需要重新检查/录制；没有手动替代显示器映射 UI。
- 系统和目标程序可能拒绝全局热键或模拟输入，必须查看状态栏及日志；系统强杀进程无法保证执行退出清理。
- Windows 调度不能保证设置 1ms 就达到 1ms 精度。
- 捕获输入框中 Esc 用于清空，不能通过该框选择 Esc 为目标键。
