KeyMouseMaster 使用说明

1. 软件简介与安装

支持目标为 Windows 10/11 64 位。拿到编译部署后的完整目录后，双击 KeyMouseMaster.exe；调试版本名为 KeyMouseMaster_d.exe。不要只拷贝 EXE，必须保留随附 Qt DLL 和 platforms/qwindows.dll 等运行文件。

通常无需管理员权限。Windows 的 UIPI 会阻止低权限程序向更高权限程序注入输入；若目标程序以管理员身份运行，按需要手动以管理员身份启动 KMM。提升权限不是所有程序都能接收模拟输入的保证。

首次进入有鼠标连点、键盘连点、脚本录制三个页面。一次只能运行一项任务。配置保存在当前用户的 QSettings 中；正常 Windows 运行使用 HKEY_CURRENT_USER/Software/KeyMouseMaster/KeyMouseMaster。日志优先写入程序目录的 log，不可写时回退到当前用户应用数据目录。

2. 鼠标连点

  • 选择左键、右键、中键、侧键1或侧键2。
  • 选择单击、双击、长按、仅按下或仅释放。
  • 选择当前位置、固定虚拟桌面坐标，或指定显示器及屏幕内坐标。固定坐标允许负数。获取当前位置会读取点击按钮时的光标位置，远处目标建议先从状态栏读取并手动填写。
  • 设置间隔（毫秒或秒）、按压时长、双击间隔、启动延迟及次数；需要持续执行时勾选无限循环。
  • 点击启动，或按默认 F7。再次按 F7 或点击停止结束；Ctrl+Shift+F12 可紧急停止。

间隔按两次操作开始时间计算；操作本身耗时更长时，以实际耗时为准。1ms 是可配置下限，不代表 Windows 能保证 1ms 精度。单击/长按会释放按钮；“仅按下”在任务进行期间保持按下，任务完成或停止仍会清理，避免鼠标卡住。

3. 键盘连点

点击目标按键输入框，按下要捕获的键。组合键请按住 Ctrl / Shift / Alt 等修饰键，再按主键；单独修饰键在释放时完成捕获。Esc 在捕获框中用于清空。功能键、方向键和原生虚拟键/扩展标志会传给执行引擎。

输入模式只有“普通按键”和“长按”。普通按键执行一次按下和释放，不使用长按时间；长按保持指定时间后释放。两种模式均保留捕获到的 Ctrl/Shift/Alt/Win 组合键，释放时按相反顺序松开。按键间隔、长按时间、启动延迟在同一行；普通模式下长按时间显示但禁用。执行参数与快捷键并排。设置后点击启动，或按 F8；再次按 F8 停止。旧设置中已移除的模式自动回退为普通按键。

切换标签页、启动任务和退出时会保存界面参数。目标组合键的修饰键、VK、扫描码与扩展标志一并保存。任务完成/停止会释放本任务按下的键。

4. 脚本录制与编辑

在脚本页面勾选要录制的鼠标移动、点击、滚轮、键盘事件，设置移动最小间隔/距离。点击开始录制或按 F9，切换到目标程序进行操作；再次按 F9 或点击停止录制结束。

页面上半部为录制/回放配置、运行控制和文件操作，下半部为脚本信息、最近脚本及事件编辑表格。普通桌面尺寸无需滚动查找配置；小窗口仅配置区滚动，运行按钮保持可见。停止后会把录制文档传到下方表格，包含时间戳、键鼠类型、桌面坐标及显示器信息。默认过滤 KMM 自身标记的模拟输入以及主窗口内操作。录制有 100000 个事件上限。

可以删除事件、启用/禁用、上下移动、修改时间戳、清空。时间戳须非负且按行非递减；移动行会交换操作内容但保留时间顺序。“插入等待”使选中行及后续事件顺延 1000ms，没有选中时从第一行开始；它不会插入鼠标原点移动，也不改变 v1 文件格式。当前表格不提供任意坐标、目标按键的专用编辑器。

填写名称和说明后点保存，首次保存会选择路径；另存为写入另一文件。扩展名 .kms，内容为 UTF-8 JSON。导入/替换未保存脚本或正常退出时会提示是否放弃修改。

5. 脚本回放

点击导入选择 .kms，或点击最近脚本。确认显示器和目标程序位置，选择 0.5x、0.75x、1x、1.5x、2x 速度，设置启动延迟、次数、无限循环和每轮间隔。

点击开始回放或按 F10。再次按 F10 或点击停止回放结束；紧急停止也可用。默认跳过禁用事件，可关闭此选项。回放按时间戳执行，保留第一条事件前的等待；每轮结束及中途停止都会释放按下的输入。恢复光标选项仅在正常完成时恢复原位置，紧急停止不再移动光标。

回放期间不能导入、替换或编辑脚本。录制/回放不会识别目标窗口，启动前需把目标窗口放在正确位置并获得焦点。

6. 全局快捷键

功能默认键可配置
鼠标开始/停止切换F7鼠标页面
键盘开始/停止切换F8键盘页面
录制开始/停止切换F9脚本页面
回放开始/停止切换F10脚本页面
紧急停止Ctrl+Shift+F12固定
关闭窗口Alt+F4按当前关闭行为处理

点击快捷键框后按新组合键；Esc 清空该功能热键。捕获期间临时暂停全局注册，结束时恢复，修改立即生效。内部冲突会提示并恢复原键，Windows 注册失败会写日志和状态栏。任一功能切换热键在已有任务运行时用于停止当前任务，不会同时启动另一项任务。

运行 → 恢复默认设置（Ctrl+Shift+R，仅 KMM 窗口内有效）会先询问确认，确认后停止任务、释放输入，并恢复参数、快捷键和窗口设置；保留当前脚本文档及磁盘文件。取消则保持原状态。托盘“输入状态复位”只停止任务和释放输入，不清除设置。

7. 紧急停止与输入复位

Ctrl+Shift+F12 用于任务失控、点击位置错误或需要马上收回控制权。它停止连点/回放/录制、等待执行线程结束、释放输入并恢复界面。若该快捷键被系统或其他程序占用，请先解决状态栏的注册失败提示再启动持续任务。

托盘“输入状态复位”也会停止任务并释放输入，不清除配置。

8. 多显示器与 DPI

状态栏显示 Windows 虚拟桌面物理坐标。副屏放在主屏左侧或上方时，负数是正常现象；不要把 Qt 窗口逻辑尺寸直接当作录制坐标。

  • 虚拟桌面绝对坐标：适合布局、分辨率和目标位置不变的情况。
  • 显示器相对坐标：按设备名加屏幕内像素定位，显示器平移后仍可定位。
  • 显示器比例坐标：按当前显示器分辨率缩放位置，比例定位不能保证目标应用的控件布局不变。

运行中检测到显示器布局/分辨率/DPI 变化时会停止坐标任务。缺失设备或越界位置会拒绝/停止回放；当前没有替代显示器映射对话框。调整布局后请检查预览、坐标模式和目标位置再重新启动。不同硬件布局需在实际环境中确认回放位置。

9. 菜单、窗口与托盘

最小化可隐藏到托盘；双击托盘图标或选择“显示主窗口”恢复。托盘菜单可启动当前页任务、停止任务、复位输入和退出；脚本页的“启动当前任务”表示回放当前脚本。托盘提示与任务状态同步。

默认关闭窗口会询问直接退出或最小化到托盘。直接退出及托盘退出会停止任务、卸载 Hook、注销热键、释放输入并保存配置。强制结束进程/系统崩溃不属于正常退出清理保证。

文件菜单的导入、保存和另存为与脚本页面共用操作。运行菜单启动对应任务，任务运行中启动菜单暂不可用；停止可用页面按钮、全局快捷键或托盘菜单。文件和托盘中的“退出”直接进入退出流程，未保存脚本仍会提示。

视图菜单可切换“总在最前”“显示状态栏”，或隐藏到现有系统托盘。窗口会记住用户大小、位置和最大化状态；首次使用按页面内容及当前屏幕选择默认尺寸。

帮助菜单可用默认浏览器打开本地说明，或访问 GitHub 项目主页和问题反馈入口。“关于 KeyMouseMaster”支持选择文字与复制全部版本信息。

10. 管理员权限说明

通常使用普通权限即可。Windows UIPI 会阻止普通权限程序控制管理员程序；目标程序提权时可按需要以相同权限运行 KMM。请只对自己有权操作的程序使用自动输入。

11. 常见问题

  • 快捷键没有反应：检查快捷键是否为空、是否仍在捕获框中、状态栏是否提示注册失败；用按钮确认参数是否有效。确保运行的是最新构建，旧版可能仍占用同一组热键。
  • 快捷键被其他软件占用：关闭冲突程序或改为未占用的组合键；部分系统保留键无法注册。
  • 无法控制管理员程序：通常与 UIPI 权限隔离有关，按需让 KMM 与目标程序运行在相同权限级别。
  • Hook 被安全软件阻止：检查日志中的安装失败提示，按所在环境的安全规则处理；没有安装成功就不能录制，不应把空白脚本当成功。
  • 多显示器回放位置异常：核对 Windows 排列、缩放、设备名、回放坐标模式和目标窗口位置；重新录制通常比猜测旧坐标可靠。
  • 脚本无法打开：确认是 KMM v1 .kms JSON，检查格式名、版本、事件类型、时间戳和键码；导入失败保留当前文档。大于 128MiB 的文件会拒绝读取。
  • 保存失败：选择可写目录，检查文件是否被其他程序锁定。失败时不会宣称保存成功，也不会用半写入内容覆盖旧文件。
  • 缺少 Qt DLL 或 platform plugin：使用完整部署目录，请使用发布者提供的完整运行包，不要混用其他 Qt/MinGW 的 DLL。
