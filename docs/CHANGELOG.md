# 变更记录

## 页面布局调整（2026-09-22，工作区未发布）

- 脚本页面改为上方配置与常驻运行控制、下方元数据和事件表格；配置区按控件尺寸换行并为小窗口提供局部滚动。

## 1.0.0 稳定性修复（2026-09-21，工作区未发布）

- 修复 Hook 处理循环错误运行在 GUI 线程、停录前队列未排空、过滤事件被当作原点鼠标移动的问题；处理 Hook 安装失败并保留完整录制文档。
- 修复回放等待函数为空导致时间戳/速度失效，支持可中断等待、暂停时间补偿、逐轮及停止后输入清理。
- 修复线程对象泄漏、启动长延迟无法及时停止、平台对象早于引擎析构，以及旧线程通知污染新任务状态。
- 接通 UI 参数、组合键完整信息、显示器内部坐标、录制文档与托盘任务控制；修复热键捕获后恢复旧注册和失败提示。
- 修复脚本坐标模式往返、非法事件校验、导入失败破坏当前文档、QSaveFile 写入/提交错误处理及“插入等待”意外移鼠标。
- 补充配置持久化、扩展键释放、显示器变化检测、统一坐标映射、日志轮转并发保护及 Qt 5/6 原生事件签名兼容。
- 新增针对上述故障的 Qt Test / Windows API 回归；规范影子构建输出，修正本地 VS Code 工具链配置。
- 将旧需求方案及重复的状态说明整理为 docs 中的使用、架构、开发、测试及待办文档。

实际构建和运行结果以[测试记录](test-plan.md)为准；本条不表示所有硬件场景均通过。
