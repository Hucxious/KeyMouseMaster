## 线程模型

```
GUI 线程                    工作线程
─────────                  ─────────
- 界面渲染                  - 鼠标连点循环
- 用户交互                  - 键盘连点循环
- 原生消息接收              - 脚本回放
- 状态更新                  - 钩子事件处理
- 钩子回调(轻量)            - 日志文件写入
```

线程通信：`信号槽 (Qt::QueuedConnection)` + `std::atomic_bool` 停止标志

## 坐标系统

```
虚拟桌面坐标 (可能负值)
    ↕ CoordinateMapper
Windows SendInput 绝对坐标 (0~65535)

虚拟桌面坐标 → 显示器内部坐标 (0 ~ W, 0 ~ H)
    ↕
显示器比例坐标 (0.0 ~ 1.0)
```

## 关键设计决策

1. **录制使用绝对时间戳**：避免误差累积
2. **显示器相对坐标优先**：防止显示器重排后坐标失效
3. **固定 dwExtraInfo 标记**：软件自有事件可被钩子识别过滤
4. **QSaveFile 写入脚本**：防止写入中断导致文件损坏
5. **紧急停止释放所有输入**：防止按键卡住
6. **同一时间只运行一个任务**：TaskManager 状态机控制
